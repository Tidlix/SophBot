# Was ist der SophBot
Der SophBot ist ein von Tidlix entwickelter Discord- und Twitchbot.
Er ist für alle Funktionen auf Discord, und ein paar kleinere Funktionen auf Twitch zuständig, und ist dabei in der Community von der kleinen Twitch-Streamerin Sophia (https://twitch.tv/xsophe) aktiv.

# Funktionen des SophBots:
Der SophBot hat noch einige weitere Funktionen, hier sind allerdings nur die wichtigsten Aufgezählt!

## SophBot AI
Diese Funktion wurde das erste mal am 09.05.2025 in der Version SophBotV1 vorgestellt. Diese Version der SophBot AI lief damals noch mit der API von Groq und hatte keinerlei besondere funktionen, sowie kein Gedächnis an vorherige Chats.
Seit dem 08.07.2025 un dem Release vom SophBotV2 läuft dieses Feature nun auf Gemini 2.5 Flash, mit einer Verbesserung der Systemanweisungen, sowie einem Gedächnis vorheriger Chats, seit dem Start der aktuellen Session. 

In der SophBotV3 Version erhällt dieses Feature nun erneut ein Upgrade. Nun ist die SophBot AI auch auf Twitch aktiv und kann Plattformübergreifend mit Nutzern interagieren. Zudem hat die AI nun mehr Funktionen, womit sie sich z.B. Informationen in einer internen Datenbank speichern kann, um diese auch nach einem Neustart nicht zu verlieren, Das Internet nach Informationen befragen kann. 
Weitere Funktionen sollen in Zukunft folgen.

Die Nutzung der SophBot AI kann wie folgt stattfinden:
- Discord:
  - /ai <Promt> - Standart Command für eine Anfrage im öffentlichen Chat.
  - DM - Jede Nachricht die an den Bot privat gesendet wird, wird an die SophBot AI geschickt. 
- Twitch:
  - !ai <Promt> - Standart Command für eine Anfrage im öffentlichen Chat.
  - @SophBotV3 - Mention Command für eine Anfrage im öffentlichen Chat. (Hinweis: Bei direkten Antworten auf eine Nachricht des Bots, wird diese Option automatisch genutzt)
  - DM - Jede Nachricht die an den Bot privat gesendet wird, wird an die SophBot AI geschickt. 

## Soph-Wiki
Das Soph-Wiki war eine ursprünglich als Spaß-Internetseite gedacht, welche allerdings recht schnell verworfen wurde. Bis das Wiki dann schließlich doch in der SophBotV2 erschienen ist, allerdings nicht als Internetseite, sondern als Interaktives Discord Embed. In dem Wiki sind seit dem einige Informationen über Community, Insider und Co. aufrufbar.

In der SophBotV3 wird das System neugeschrieben, um vorallem die Erstellung und Bearbeitung einzelner Artikel zu vereinfachen (bisher musste Tidlix alles manuell einfügen). 

Das Aufrufen des Wikis ist nur per Discord mit dem Command /wiki [Artikel] möglich
